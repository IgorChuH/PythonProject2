# Приложение для анализа транзакций.

## Описание:

Данный проект - это курсовая работа, направленная на развитие базовых производственных навыков, связанных с профессией Python-разработчик. Тема работы разработка приложения для анализа транзакций.

## Установка:

1. Клонируйте репозиторий:
```
git clone https://github.com/IgorChuH/PythonProject2.git
```
2. Установите зависимости:
```
-pip install -r requirements.txt
```

## Инструкция:

###Главная функция:
1.Для использования приложения вам необходимы файлы operations.xlsx и user_operations.json. В них содержутся данные для работы приложения, которые вы можете сменить в директории data.
2.Главная функция main в модуле views.py создана для обработки данных транзакций и получения сводной информации. Возвращает JSON-строку с результатами, включающими. В случае неверного формата даты возвращает JSON с ошибкой. Вспомогательные функции содержатся в модуле utils.py.
3.Модуль services.py выполняет поиск транзакций по заданному текстовому запросу в описании и категории. Возвращает JSON-строку с результатами поиска — список словарей, где каждый словарь описывает транзакцию, соответствующую запросу.
4.Модуль reports.py рассчитывает суммарные траты по заданной категории за последние 3 месяца от указанной даты. В процессе работы выводит отладочные сообщения с информацией о дате и промежутке фильтрации, а также итоговой сумме.
